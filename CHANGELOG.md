# Changelog

## v0.7: iPhone ready (27 Sep 2026)
- Hosted on GitHub Pages so the iPhone can install it to the Home Screen.
- Backup files can be picked on iPhone (the file picker no longer greys out .mizan files).

## v0.6: Reset pots (27 Sep 2026)
- Any pot can be reset to 0. The money goes to another pot, or is cleared if it's already gone.
- Resets appear in History and can be undone by deleting them there.

## v0.5: Your own pots & sources (27 Sep 2026)
- Removed all preset sources and pots. Mizan starts with Sadaqah, Savings & gold, and Me.
- Add pots with name, icon, color, and share. The share is taken from "Me", so the total stays 100%.
- Add sources straight from the Money-in screen.
- Existing data: old preset pots were removed and their money moved into "Me".

## v0.4: Black & gold (26 Sep 2026)
- Extra sadaqah for one income, with a warning. Other entries keep the normal %.
- New black & gold theme and app icon.
- Animations: count-up numbers, page transitions, sliding sheets, gold-coin rain, confetti.
- Glow on the active tab.

## v0.3: Simpler + undo window (26 Sep 2026)
- Money-in entries can be undone for 10 minutes, then they're final.
- Redesigned with 4 tabs (Home, Add, Goals, More), simple icons, a "To do" list, and advanced settings folded away.

## v0.2: Private & more features (26 Sep 2026)
- PIN lock with AES-256-GCM encryption, auto-lock, encrypted backups.
- Monthly report, gold value, zakat check, goals with dates, per-source splits, loans, Arabic.

## v0.1: First version (26 Sep 2026)
- Offline money splitter: sadaqah, savings with the gold rule, pots, spending, to-buy list, history, backup.
